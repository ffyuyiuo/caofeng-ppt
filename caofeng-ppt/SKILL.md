# 电影级 PPT 制作（caofeng-PPT）

## 什么时候用

- 用户给一份 Word（报告、方案、复盘、路演、手册）要变成"高级感/电影感/会动"的 PPT。
- 用户要 AI 生图/生视频提示词，且要求提示词是**照着真实成片写法**来的，不是网上那种三行咒语。
- 用户要"自动找图"，且明确要求高清、无水印、许可说得清。

不适用：只要纯文字大纲、或用户要 HTML 演示（走 dashi-ppt）、或要常规办公汇报模板（走 human-doc 的 pptx_build）。

## 七条不可让步的硬约束

1. **成品必须可编辑**。AI 生成的图/视频里**不许有文字**，所有文字由 PPT 文本层叠加。这是整套语料里最重要的一条纪律（49 段提示词里 23 段明写"不要出现任何文字/Logo/水印"）。
2. **参数不许凭感觉**。每页的动效方案要指到 `kb/deck_tech.json` 里的技法卡；卡的数值全部来自 171 模板 OOXML 实测。
3. **素材必须可举证**。每条素材要有 url、许可、尺寸、SHA1；拿不到就降级为矢量色场，**不放占位假图、不用盗版图**。
4. **闸不过不出片**。`check` 报不合格就回去改，不许用"应该没问题"交差。
5. **验收要真渲染真看图**。统计全绿≠画面成立；必须 WPS 导出 PNG 逐页看过。
6. **不编造能力，也不偷消耗积分**。本机没有图像/视频生成模型可用：出图、出视频、出动图**一律走豆包/即梦网页版
   免费额度**（用户已确认），技能负责把提示词、附件、点击步骤、回收文件名全部备齐；
   **禁止用 Qoder 自带 ImageGen 出图**（消耗用户模型积分且烧「AI生成」水印）。全自动只允许两条：
   联网抓 CC 授权照片、以及矢量色场/`make_gif.py` 这类零模型调用的确定性生成。

7. **联网口径固定**。**国内资源直连，不许挂代理；国外资源（GitHub、Wikimedia Commons 等）才走本地代理**。
   代理地址默认 `http://127.0.0.1:7897`，可用命令行 `--proxy` 或环境变量 `CAOFENG_PROXY` 覆盖为你本机的实际端口。
   `fetch` 已按域名判定（`caofeng.py is_foreign`），手动下载/查资料也按这条走；不许擅自换成其它代理或国外模型服务。

## 学习方法（用户 2026-11-07 硬要求：音画同时学，不许只截成品页）

只把每页 PPT 截图去学会掺进**错误示范**（视频里"改之前"的平涂柱/默认图表/直角方框正是被否的那版），
而且片面、形不成完整的设计与制作逻辑。正确做法四维同时：

1. **听**：faster-whisper 逐句带时间戳稿（`kb/transcripts/`）；
2. **看**：按每句时间中点抽帧（`study_video_logic.py`），放大 2× 重 OCR，音画对齐成
   `kb/video_logic.json` + 逐视频 `kb/video_logic/<id>.md`；
3. **对照操作**：从对齐链里提取 点了哪个键 / 改了哪些参数（透明度/字号/磅/秒/间隙宽度/三维旋转）/
   哪些排版被否（"不行/太挤/删掉/去除标题图例网格线"）；
4. **人工读帧补设计意图**：OCR 读不出的构图逻辑由 agent 亲自读关键帧补进
   `kb/video_logic/DESIGN_LOGIC.md`（数据页操作链、指标卡红绿箭头、立方体柱、表格递进带色无框线、
   图进形状遮罩、动态背景尾帧封面+自动播放）。

做新 deck 前先读 `DESIGN_LOGIC.md` 与 `kb/layout_archetypes.json` 的 archetype_max_pt_median /
archetype_share 定构图与字号阶梯；**别从成品截图反推"模板长这样"**。

## 构图与字号阶梯（装配默认，G27 守下限）

做每一页前先定构图，再填内容（出处：`kb/video_logic/DESIGN_LOGIC.md` + `kb/layout_archetypes.json`）：

- **满幅页用满幅文字区**（0.84 宽），不要沿用分镜为分栏写的窄 reserved_zone；分栏页才用窄区。
  正文 ≤2 行的带图页一律 full-bleed 压字，不分栏（语料 full-bleed 压字率 99.2%）。
- **字号阶梯**：页标题 48pt 起（收至 32）、正文 20/18/16、页底数字卡 60pt 档 + 半字号单位 +
  ≤6 字类别名、柱顶数值 32pt 档、稀疏页（整页 ≤28 字）居中大字 56–60pt。G27 守下限：整页最大字 ≥32、
  正文行 ≥16；小字浮在半页空底上会被拦。
- **数据页**：≥3 个同单位数值才画条形组，且**每条都要有类别名**（2–6 字名词短语，'名女性提供乳腺'
  这种半句话不算）并且最大/最小 ≤25 倍——不满足就退回大数字/筹码，把不可比的数画成一组柱子是假数据
  （G8 `naked_charts` 拦）。画法按语料比例：细柱（柱宽 ≤0.085 页宽、柱高/柱宽 ≥1.6）+ 满槽高轨道 +
  承载面板 + 竖向渐变 + 立方体帽 + 柱顶白字 + 柱底类目；2 个并列数值画页底数字卡（一格一卡，
  卡宽 ≤0.32、整排居中）；有"同比/增长/下降 x%"画指标卡（圆图标 + 大数字 + 红绿箭头）。
- **数字上屏必须读得通**：标题/筹码里的数字不许被裁成原文更长数字的前缀（'覆盖 82' ← '82,340 例'，
  G24 `truncated` 拦，装配侧 `repair_head_number` 自动补回并带上紧跟的量词）；裸数字要跟着原文的
  量词或类别名（'500 名女性'、'主动说 18.9%'），不许只打 '500'、'15'；字数预算切在中文词中间时
  退回最后一个"数字+单位"，宁可少信息也不留断头词。
- **表格**：递进透明度带色（3/5/10/20…%）、四边无框线、行高按留白区摊满（0.45–1.10in）、
  表头 20pt/正文 16pt、数字列右对齐 + 每列最大值亮青加粗。
- **无素材页**：母题三套按页序轮换（同心圆居中/偏右上/点阵），相邻页不同脸；G20 连排按同母题计。
- **图进形状不进方框**：分栏 hero 图用 diamond 遮罩、栅格 tile 用 roundRect；离题/低清图拒用降级，不凑数。

## 人工投放的等待与续接（不许中途宣布完成）

视频与动图要由用户在网页版（豆包/即梦）点生成，这一段是**人工门控**，不是能力缺失。协议固定四条：

1. **一页一轮地发**：`pack` 之后跑 `caofeng.py card --work DIR`（不给页码自动取队列里最早待回收的
   一页，视频优先；`--page N` 指定页），把它的 stdout **整段原样**发给用户——含该页每种提示词全文、
   负向词、回收指令与收件文件夹路径。**必须把每段提示词用代码块贴进对话回复正文**，让用户直接
   复制粘贴到豆包/即梦；**不能只留在 Bash 工具输出里**（用户看不到工具输出、无法复制，2026-11-09
   用户明确否掉："提示词卡为何没在 agent 中弹出，不利于复制粘贴"）。**禁止把整册 `delivery_card.md` 丢给用户**（238 页的卡几十万字，
   用户 2026-11-07 明确否掉："太不利于我操作"）。用户回「好」→ `pickup --work DIR --page N` 认领
   （引擎自己找最近下载、验分辨率/时长、改名进 gen/ 并在项目 `PPT素材\AI产物` 留档）→ 再 `card` 发下一页。
2. **每页只问一次固定问题**：「这一页的图/视频下载好了吗？好了回 **好**，我认领后继续下一页。」
   回复"好"以外的任何内容（含修改意见）都按意见改该页提示词，重跑 `pack` 后再发该页。
   口令分两层，别混：**一页一轮回「好」**（走 pickup 认领）；**整册投放就绪回「是」**
   （走 `ack --ready`，build 只认这个回执）。整册全部回收完才 `ack --ready`；
   用户明确说"剩下的不做了"才 `ack --declined --note 用户原话`，agent 不能替他回。
   单页视频清不净而用户选静态兜底：**这一页**用 `waive --work DIR --page N --note 用户原话`
   （原片留证 AI产物、决定记 video_waiver.json、队列跳过该页，见下面 §流水线注释）；
   `ack --no-video` 只在用户明确说**整册都不要视频背景**时才用，它豁免的是全册 video 类，
   不是某一页。两种兜底最后 build 都是把静态底图真做成满铺缓慢推镜 mp4（末帧做 poster）
   再 attach_video——与语料封面同构。**不许**用 animScale 推镜
   满铺图（PowerPoint 放映态会缩成灰底小缩略图，用户实测否掉，G29 拦）。
3. **等待不是结束**：素材未回传时**不得**输出"已完成/交付完毕"、不得把 goal 标 completed、不得删改工作目录。
   这条不靠自觉：G11 会把"写了提示词却没有产物"的页判成硬伤，`check` 退出码非 0，本来就无法宣布完成。
4. **续接靠工作目录，不需要状态文件**：`--work DIR` 本身就是断点（outline/shots/promptpack/gen/out/report）。
   用户回「是」→ `ack --work DIR --ready` → `build` → `check --render` → `shots`，全绿才算交付
   （**没有 ack 回执 build 会退出码 1 停住**，见 G26，所以上一步不能跳过）；跨会话重跑同一目录即可继续，
   不要要求用户重述需求，也不要重新分镜。


## 开场五问与页数契约（SPEC §21，G23 硬拦）

用户说"把这份文档做成 PPT"时，**先问五件事再动手**：① 多少页（或区间，如 25-35）；② 什么场合
（路演/汇报/评审/留档）；③ 讲给谁（投资人/领导/客户/内部）；④ 模板风格（六块色板×九版式，给 2-3 个
候选说清差异让用户挑；`CORPUS_DIR` 171 套是尺子不是产品模板库，不许整套套）；⑤ 要不要逐字留档册。
拿到原话跑 `plan --pages N --occasion … --audience … --note 用户原话`；用户明确说"页数你定"才许
`--auto-pages`。**没契约就 plan 会打印五问、check 的 G23 会硬拦**——不许自作主张把 Word 自然分页
全铺上去（实测 250 页被用户否："页数太多了"）。
`--pages` 会重新梳理 Word：结构页不动、章内内容页相邻合并精确凑到目标页数，正文一句不丢；
`refine` 写压缩台账（原文留账、上屏是提炼句），G13/G24 按台账核，不许静默丢内容。


## 七阶段流水线（含两处必须由人参与的回合）

> S3 提炼与 S5 投放回执是新增的硬步骤：**分镜后必须先 `refine` 改写每页 display_lines**
> （≤2 条、每条 ≤14 字、数字一个不许丢），**`pack` 之后必须把投放卡全文发给用户并等他回答**，
> 回答用 `ack` 登记；没有 ack，`build` 会退出码 1 停住。图片另可走 Unsplash 中文站
> （卡片给检索 URL，hover 点 ↓ 下原图），下载回来的图必须 `fetch --adopt` 登记来源才许进成品。


工作目录统一用一个 `--work` 目录，所有中间产物落在里面，可反复续跑。

```bash
S=~/.qoder-cn/skills/caofeng-PPT/scripts
W=<本次作业目录，例如 CAOFENG_WORK/job-名称>

python $S/caofeng.py plan   "<docx路径>" --work "$W"          # S1 解析 Word → outline.json + shots.json 骨架
python $S/caofeng.py refine --work "$W"                       # S2 给每页 display_lines 出提案（agent 必须再逐页改写）
#   refine 只写"提案"（shots 里 display_is_proposal=true、needs 标记）；按 SPEC §12 逐页改成
#   ≤2 条、每条 ≤14 字、数字一个不丢的最终文案，改过的页别用 --force 覆盖。
#   display_lines 全空的页会被 G23/G24 拦，不许跳过这一步直接 pack。
python $S/caofeng.py fetch  --work "$W" --source auto --min-edge 1920 \
       --term "3=英文搜索词"                                    # S3 联网取高清无水印素材（图片短边默认 1920）
python $S/caofeng.py fetch-video --work "$W"                  # 视频先联网找无水印 CC 素材（SPEC §23）
#   找不到贴合的才回豆包/即梦兜底；联网视频水印零容忍（叠加层/角标/烧字任一命中即拒）
#   联网优先：fetch 逐词重试搜到过闸为止（相关度→水印→带字/历史画→美学闸），搜尽才豆包/即梦兜底；
#   美学闸：离色板饱和像素>25%/边缘>0.035/亮度>0.5 拒（SPEC §24）；source=stock 举证页豁免美学闸
python $S/caofeng.py materials-review --work "$W"               # 拼联系表给 agent 真看；看完 --set "3=keep,4=reject:理由"
#   检索词优先读 shots.json 每页的 search_terms（2-3 个英文具体实物词，从该页自己的
#   display_lines/实体派，不许按页号猜）；fetch 逐词重试直到拿下。下载后还有画面质检：
#   带字图（文字像素>2%）/engraving/sketch/插画/海报一律拒——词面相关度满分也拦不住语义离题。
#   目检留痕是 G3 硬要求：review.json 每页 keep 才许上屏，reject 自动摘出 manifest。
#   检索词写法（实测踩出来的，别改回去）：英文、只写画面里看得见的实物名、2–3 个词。
#   词必须描述**页面主体**，不是猜一个字面物体：页讲"待筛查的三亿女性"却搜 'health screening van'，
#   抓回来的是美国 NIOSH 职业安全卡车——词↔图相关度满分、语义离题（2026-11-08 目检抓出）。
#   拿不准就宁缺：缺页降矢量色场，不放假图。
#   fetch 之后、build 之前必须**亲眼看一遍新素材**：把本轮 manifest 里的图拼成带页码+标题的
#   联系表（PIL 缩略图拼图即可）逐张对页面主体。G3 的相关度尺量的是"词↔图标题"，
#   词选错时它给满分也拦不住语义离题——实测一轮 15 张里 6 张离题（军机舱当流动医疗车、
#   cosplay 当中国街景、空间站显微镜当 meta 分析）。离题的页用 --only-page 换词重取，
#   换不出就降色场；不许因为 G3 绿了就铺上去。

#   素材落点（用户的硬要求，每个项目不一样，绝不写死路径）：
#   plan 会在 Word 文档旁边建 <项目>\PPT素材\（收件 / 实拍 / AI产物）。
#   用户把网页下载的文件丢进 <项目>\PPT素材\收件，然后跑
#   python $S/caofeng.py pickup --work <目录> --page N
#   **命名规则（卡上必须写给用户）**：一次只下一页可不改名；同时下好几页时按页号命名——
#   图 `p011_image.png`（`p011_图.png` 也认）、视频 `p011_video.mp4`（`p011_视频.mp4` 也认）、
#   动图 `p011_anim.gif`。pickup **页号命名优先**；没命名时同类候选只有一个才按"最近 45 分钟"认，
#   多于一个就列出文件名停下来问（或让用户 --src 指全路径），**绝不猜对应关系**——
#   用户明确要求"避免图片视频一多 agent 识别错"。认领后当场验短边≥1080（视频还验时长≥3s）、
#   复制进 gen/pNNN/ 并在 PPT素材\AI产物\pNNN\ 留一份，已认领的按 SHA1 不再重复认。
#   水印（2026-11-09 用户回件实测升级，SPEC §19）：免费档豆包/即梦**视频**水印会淡入、
#   漂移（实测右下 0–3.7s → 淡出 → 左上 4.4–7.5s → 溶解成彩色块）、淡出，
#   抽右下角和逐帧角区 TELEA 两条都治不了它。pickup 认领后走 `lama_cleaner.clean_cover_video`：
#   ① 从最清晰帧的窗口并集框内抠水印模板（`build_wm_template`），逐帧四角模板匹配定位；
#   ② **裁角优先**：水印只落四角带内 → `crop_out_corner_watermark` 物理裁中央 16:9 再放大
#      （零残留零补痕；裁切带按确认框自适应、封顶 320px，放大倍率如实报告，实测 1.69x）；
#   ③ 验收=几何证明（每个确认水印框都在裁切矩形外）+ 高阈值 0.45 模板匹配零命中。
```

## 决策顺序（每页都要走一遍）

1. **这页只讲一件事**：语料 2224 页里 33.5% 几乎无字——但那批页多半是作者自己的推广页，

2b. **图文重排**：先定这一页走哪种实测原型（`references/deck-craft.md` 的重排表）。

## 提示词怎么写（详版在 references/prompt-grammar.md）

- 图片：**九段式**——主体特征 / 构图方式 / 镜头角度 / 光线方向 / 色彩搭配 / 材质细节 / 背景元素 / 画面风格 / 画面参数。实测均值 **809 字**。
- 视频：**六段式**——参考帧声明 / 全局参数 / 秒级分镜 / 因果顺序 / 运动约束 / 定格收束。实测均值 **1011 字**。
- 动图：**六段式**——参考图声明 / 全局参数 / 循环声明 / 秒级分镜 / 运动约束 / 背景与叠加。
  必须写"无缝循环（首尾一致）"与"透明或纯黑底"，否则放进 PPT 会播一次就停、或带一块方框底色。

- 负面：**三类名词清单**——技术缺陷 + 内容禁区 + 结构一致性。不许写动词句。
- **主体必须直写"画面里是什么"**（语料原话就是"画面中央是一支巨大的向上指引箭头，由明亮的青蓝色
  半透明能量光束构成…象征突破、增长"）。旧模板那句"设置**与「章节名」直接相关的核心视觉主体**"
  实测 230 张图卡里 211 张在用它、101 页主体句逐字相同 → 模型只能猜，整册出同一类抽象图，
  用户看到的就是"同一段提示词反复发"（SPEC §20）。现在 `scaffold` 会把画不出的主体按页面实体
  自动翻成具体画面（`shots.json` 标 `subject_auto=true`，原料变了每轮**重算**、不复用旧句），agent 还要逐页改得更贴文档实体；
  `pack` 三条硬判据兜底：间接句式出现即拦、两页主体句逐字相同即拦、「主题为「X」」/「象征Y」不是
  完整短语即拦（虚词收尾、单字序号、纯数字、`·数字`粘碎片都算半句话；洗不出就省掉象征句，
  绝不硬截——尺子在 `styles.clean_phrase`/`phrase_ok`，生成与复核同一份，SPEC §25）。
- **首帧附件只有一个口径 `card_first_frame`**：只认这一页的专属静帧（gen 出图 → manifest 验收过的

  没有专属静帧的过渡页，卡会自动变成**两步**：先按本章主题文生图，再把刚下载的那张图当首帧生成视频。

  card_first_frame），拿被封面规则替换过的 poster 当尺子会恒等成立，闸会直接报"量不出结果"。
- 三条必写：① 留白占位区（"容器内部保持完全空白，不放任何文字"）；② 文字禁令；③ 附件点名（"以附件1作为首帧"，

  出来的视频两者都不是（芯片展台），G15 MAD 32/255 拦下——指错文件等于白跑一轮投放）。

## 复现这套研习（语料更新后重跑）

研习脚本只读语料、只写工作目录。语料目录由 `scripts/corpus_path.py` **单点解析**，顺序是：
`CAOFENG_SRC` → `kb/corpus_src.json` 里上次用过的目录 → 历史默认 → 自动定位（在 `D:/`、桌面、
文档里下探两层，找 `.pptx` 最多且 ≥100 个的那个目录，找到就写回记忆文件）。

`CAOFENG_WORK`）决定，不存在时脚本**直接停并退出码 2**，不会在别的盘上凭空建一个
`caofeng_work`——这些脚本会写几百 MB 到几 GB，落点必须由你已经知道它存在。

## 已知的坑（实测踩过，别再踩）

- WPS 生成的 pptx **PowerPoint COM 打不开**，渲染验收只能走 `KWPP.Application`；`app.Visible=False` 在 KWPP 上会抛异常，要 try 掉。
- `Slide.Export` 的路径**必须绝对路径**。
- 素材原图动辄 10200×5100（37MB）。**必须先归一化到长边 3200 再嵌**——这套语料自己就是因为直嵌素材才膨胀到 106GB 的。
- 对比度不能只算解析式模型，要量渲染后的像素；背景亮度取"排除笔画像素后的中位数"，取最暗像素会把白字压亮图误判成合格。
- 自动取图必须过敏感题材黑名单与相关度闸：实测中文抽象词会从 Commons 捞出抗议/宗教类照片。
- **禁止调用 Qoder 自带 ImageGen 出图**：它消耗用户的模型积分（用户 2026-11-05 明令），而且右下角烧
  「AI生成」水印。要静帧就两条路：即梦「图片生成」16:9 高清/2K 档（人工一键，免费额度），
  或 S3 联网抓 CC 授权真实照片（全自动、可举证）；两条都不成就用矢量色场，不许拿 ImageGen 兜底。
- 历史坑（禁令之前踩过，留作证据）：ImageGen 的默认落点是**当前工作目录的 `vibe_images/`**，
  在语料目录里跑会污染交付文件夹。现在按上一条根本不该发生；若别的任务误跑过，
  必须立刻把图移出并删掉 `vibe_images/`。

- 视频页的 timing 树标签必须逐层闭合，`p:video/cMediaNode` 是 `tmRoot` 的子节点，不是 `tnLst` 的。
