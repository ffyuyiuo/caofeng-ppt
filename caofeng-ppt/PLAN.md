# caofeng-PPT 同级升级计划（v3.0）

目标（用户原话拆解）：让 agent 用本技能做出的 PPT，与
`CORPUS_DIR/PPT视频教程` 的 24 条教程视频演示的效果、以及 `CORPUS_DIR` 的 171 套模板
**同等级**。达不到就继续迭代，不得中途断供。

判据不是"我觉得像"，而是 SPEC §11 的实测分布 + §12 的提炼契约 + §13 的互动回执，
全部落在闸上（G22–G26），每道闸都有反向自证。

## 根因（已实测，别再重复发现）

1. **契约错了**：旧 G13 要求 Word 每句逐字上屏。2.5 万字只能做成 175 页、每页 100–300 字；
   而语料好示范页 p50 = **19 字**、p75 = 44 字。差一个数量级，怎么调色都追不上。
2. **数据表现手法缺位**：语料真表格页只占 0.7%，数据靠大数字（35.6% 的页有 ≥60pt 数字）、
   卡片栅格（17.8%）、条形（5.8%）、时间轴（8.7%）表达；装配器只会画 `<a:tbl>`，等于把台账当版式。
3. **互动缺失**：投放卡只写在文件里，agent 可以不给你看就一路 build 到底。

## 阶段与验收

### P1 教程研习入库（进行中）
- `scripts/study_tutorials` 对 24 条视频做场景采样帧 + tesseract 屏幕 OCR + faster-whisper 逐句转写。
- 产出 `CAOFENG_WORK/tutorials/{frames,frame_ocr,transcript,videos.jsonl}`，
  汇总进 `kb/tutorials.json`（每条视频：主题、操作步骤、屏幕上的提示词、涉及的技法）与 `kb/tutorial_study.md`。
- 验收：24/24 有产物、失败 0；提示词候选逐条可回溯到帧文件或 ASR 时间戳。

### P2 提炼契约（G23/G24）
- `plan` 每页产出槽位：`headline`、`display_lines[]`（空，待 agent 填）、`key_numbers[]`、
  `source_paragraphs[]`、`content_type`（要点/对比/步骤/台账/结论）。
- `build` 优先用 `display_lines` 排版；没填就报错而不是退回整段上屏。
- G23 页面预算：headline ≤18 字、display_lines ≤3 条且每条 ≤20 字、非表格页 ≤90 字。
- G24 事实覆盖：段落事实单元（数字/专名/金额/比例/时间）100% 上屏；content_type 与版式匹配。
- 验收：反向自证——把整段塞进 display_lines 必须被 G23 拦；删掉一个金额必须被 G24 拦；
  正常提炼版必须放行。

### P3 数据版式（G22 同级分）
- 新增产出：`add_hero_number()`（≥60pt 数字 + 单位 + 结论行）、`add_bar_group()`（语料条形几何）、
  `add_card_grid()`（已有 tile_boxes，补要点→卡片映射）、`add_timeline()`（步骤→共线节点）。
- `scripts/deck_parity.py`：逐页量成品六维，与 `kb/data_design.json` 分布对比，出加权分。
- G22：分数 ≥85 才出片；`--verbatim` 只能豁免并自报"这不是发布会册"。
- 验收：拿 v19 那份跑 parity，必须显著低于 85（证明指标能区分好坏）；拿语料好示范渲染跑，
  必须 ≥85（证明指标不把范本判死）。

### P4 表格重设计（G25）
- 按 `kb/table_design.json` + 发布会标准重写 `add_table()`：表头色带 + 加粗、数字列右对齐、
  行高按内容、列宽自适应、正文 ≥12pt、表外一行结论；台账只在"源本身是表"时出现。
- 验收：把 Word 表格原样贴进去的旧样式必须被 G25 拦；新样式放行且渲染后无溢出。

### P5 互动硬闸（G26）与 Unsplash
- `pack` 打印卡片全文 + 写 `delivery_request.json`；`build` 无 `delivery_ack.json` 即停并打印固定问句；
  `check` 核 card_sha1 与 gen 文件指纹。
- Unsplash：有 `UNSPLASH_ACCESS_KEY` 走官方 API 自动取；没有则每页给检索 URL + 点击级步骤，
  下载回来用 `fetch --adopt` 登记许可。署名页数量按许可统计，Unsplash/CC0 不强制署名。
- 验收：不写 ack 时 build 必须退出码 1 并把卡片全文打出来；伪造 ack（card_sha1 不符）必须被 G26 拦。

### P6 端到端重做与并排比样
- 用车联体商业计划书重做 v20：提炼版式、目标 60–90 页、每页 ≤90 字、数据走大数字/卡片/条形。
- 全部闸（含 G22–G26）+ WPS 真渲染逐页目检 + 与语料模板同尺寸并排拼图比样。
- 达不到同级就回到 P2–P4 继续改，直到达标；每轮都要重跑 parity 与自证，不许拿旧绿灯说话。

## 停止条件

- 27 道闸全绿（G1–G27），反向自证全过；
- G22 同级分 ≥85，且同一指标能把 v19 判到不达标、把语料范本判到达标；
- 逐页渲染目检确认：没有整段文字页、没有裸贴的 Word 表格、数据页有大数字或图形、每页有图或刻意的色场；
- 用户拿到 delivery_card 全文（G26 有 ack）。
