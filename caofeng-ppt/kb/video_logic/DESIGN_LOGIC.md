# 教程视频的设计逻辑链（音画对齐 + 人工读帧，2026-11-07）

方法：`study_video_logic.py` 按每句讲解的时间中点抽帧、放大重 OCR、音画对齐；
下面再由人工读关键帧补 OCR 读不出的设计意图。**只截成品页去学会学到错误示范**——
视频里"改之前"的样子（平涂柱、带标题图例网格线的默认图表）正是要被否掉的那一版。

## 数据页的完整操作链（1e2c66eafa《怎么排版》0–60s，逐句对照画面）

| 时间 | 讲解 | 画面在做什么 | 沉淀的规则 |
|---|---|---|---|
| 0–8.8 | 先给背景条一个浅蓝色，梳理文字和数据，绘制矩形形状并设置阴影用来承载数据 | 白色圆角面板垫在图表下 | 图表/数据要有**承载面板**（圆角+阴影/半透明），不能浮在空背景上 |
| 8.8–17.7 | 放大数据并设置颜色强调突出；分别给增长和下降数据设置不同颜色并绘制箭头 | 左列指标卡：大数字+小单位+红/绿箭头 | 数字是主角（26pt+）；**增长红↑、下降绿↓**，箭头是语义不是装饰 |
| 17.7–25.2 | 在数据前面绘制圆形形状放置图标增强可视化；右边绘制矩形设置阴影调节阴影 | 指标卡左侧圆形图标 | 指标卡 = 圆图标 + 标签 + 大数字 + 同比箭头 |
| 25.2–32.7 | 用来承载柱状图；**去除图表的标题、图例、网格线；勾选数据标签** | 默认图表的标题/图例/网格线被删掉，柱顶出现数值 | 默认图表三件套（标题/图例/网格线）是**错误示范**，要删；数值标签要开 |
| 32.7–40.5 | 绘制立方体形状并设置渐变；复制立方体粘贴为图片；将图片填充到柱状图中 | 右键菜单→粘贴为图片；柱身变渐变 | 柱身**渐变+立方体顶**；参数面板实测透明度 55%、三维旋转 90° |
| 40.5–49.2 | 将柱状图间隙宽度适当缩小；插入 SmartArt 箭头向上的流程图形 | 柱变宽、立方体效果成立 | **间隙宽度要小**（柱宽≥间隙），细缝柱是草稿感来源 |

被否的样子（s01 帧）：深蓝平涂柱 + 默认标题/图例/网格线 + 无数据标签 + 无承载面板。
成立的样子（s05 帧）：浅蓝渐变立方体柱 + 柱顶数值 + 白色承载面板 + 左列指标卡带红绿箭头。

## 其它视频读帧补充

- **0a439061ed（国风开场）**：首尾帧参考图导入 AI 视频工具 → 复制提示词 → 生成 → 下载 →
  拖入 PPT → **选最后一帧作封面** → 设置演示时自动播放 → 中部加标题。
  规则：动态背景要"首尾帧可控 + 自动播放 + 封面取尾帧"，否则放映第一帧是黑的。
- **表格页（2db7c536）**：表设计→底纹→其它填充颜色；第二格透明度 3%、第三格 5%、第四格 10%
  往后依次 +10%；边框改为无框线。规则：**行带色是递进透明度**（3/5/10/20…），不是两色交替；
  现代台账**去掉框线**靠带色分行。
- **图文页（NO.103/119/127 模板 + 63c441c2/7cd85682 视频）**：合并形状（结合/剪除/拆分/相交）
  把图片切成菱形/圆弧/镂空；**幻灯片背景填充**让镂空处透出底图；平滑切换做位移。
  规则：图进**形状遮罩**，不进直角方框；镂空+背景填充是"高级感"的来源之一。

## 落到引擎的对应实现

- 承载面板/渐变柱/立方体帽/柱顶白字数值：`data_layout.bar_group`
- 指标卡+红绿箭头：`data_layout.delta_cards`（页面含"同比/增长/下降 x%"时触发）
- 页底一排大数字+半字号单位+小注释：`data_layout.number_row`
- 表格递进带色+无框线+行高摊满：`caofeng.add_table`（带色按 3/5/10/20…% 递进，四边 noFill）
- 形状遮罩：`caofeng.add_picture_in_box(shape=diamond/roundRect/ellipse)`
- 动态背景首尾帧/自动播放/尾帧封面：`caofeng.attach_video` + `make_poster`（取 last 帧优先）
