# 视觉范式（逐页看渲染图归纳，不是从文字里推的）

来源：`CAOFENG_WORK/render/`（172 模板 WPS 渲染）+ `study_sheets/`（拼图）。
每条都标了能回看的模板号与页码。

## 一、封面公式（几乎全部高完成度封面都是这一种）

```
整幅 AI 写实图铺满画布（无留白边）
└ 单一主体，占画面 20–35%，位置偏离中心
└ 背景暗或高饱和，主体边缘有轮廓光
大标题：4–6 字，书法体或超重黑体，带质感（金属/描金/发光），字号 ≥60pt
小副标题：4–8 字，细体 + 大字距，压在标题下方一行
（可选）一行说明文字，落在画面下 1/3 的自然暗区
```

实测样本：NO.100 p001（锻打铁锤+火星+金色金属字"千锤百炼"）、NO.102 p001（金云雄鹰+"展翅高飞"）、
NO.150 p001（天安门红旗+"国庆节快乐"描金）、NO.154 p001（水墨群山+金色光带+"PPT动态国风开场"+红色印章条）。

**要点**：标题不是纯色，是**质感**。这套片子的"贵气"来自渐变金属/描边/外发光，不是来自配色高级。
装配时要么用带质感的图做标题层，要么用 DrawingML 渐变字 + 外发光，不要给纯白宋体。

## 二、把数据结构压在画面自己的引导线上（最高价值的一条）

NO.155「动态破浪时间轴」：航拍游艇在蓝色海面切出白色尾迹，尾迹从画面左下贯穿到右上。
**六个时间轴节点（2005-2007 / 2008-2012 / 2013-2015 / 2016-2017 / 2018-2019 / 2019-2026）
就排在这条尾迹上**，圆形图标节点贴线，文字卡片统一放在海面平静的左侧。

同理 NO.154 用金色光带、NO.160 用画卷展开线、NO.122 用画出的城市轮廓线当流程载体。

规则：
1. 先让 AI 生成一张**自带引导线**的图（尾迹/公路/河流/光带/轨道/山脊）；
2. 流程或时间轴节点沿这条线排；
3. 文字卡片全部挪到画面里**最平静的区域**（不是"空白区域"，是视觉噪声最低的区域）；
4. 提示词里必须显式要求这条线："画面下方一条白色尾浪从左下延伸至右上，作为视觉引导线"。

这条比"用 SmartArt 做时间轴"高一个量级，因为它让数据看起来是场景的一部分。

## 三、首尾帧三页式（NO.150 实测结构）

```
p001  成品场景（尾帧静帧，用来定调）
p002  首帧（一张干净的宣纸/纯蓝科技底/空白画卷）
p003  成品场景（尾帧，视频结束后停留的静帧）
```

装配成视频页时对应：首帧图=视频第一帧，尾帧图=视频最后一帧，中间交给模型补。
好处：**转场两端都是可控静帧**，讲解时视频没播完也能停在可用画面上。

## 四、形状裁切容器（布尔运算的真实用途）

NO.103 菱形介绍：四个菱形照片拼成一个大菱形，白色细描边，左侧绿书法标题+正文块。
NO.105 花瓣旋转：五瓣花形裁切季节照片，压在整幅季节背景上，标题"四月芳菲/秋意正浓/冬藏时光"
用季节色（粉/金/蓝）。

规则：**容器描边要细（1–2px 白或金）**，容器之间留等距缝隙；照片在容器内要保持同一裁切比例。
OOXML 上是 `custGeom` + `a:blipFill`，语料里 `custGeom` 出现 7785 次。

## 五、文字在忙乱照片上活下来的办法

NO.155 的标题压在深蓝海面上，仍带**蓝色外发光 + 白色描边**；卡片是半透明深蓝底。
所以顺序是：① 选低噪声区；② 加半透明卡片底；③ 字加描边或外发光；④ 最后才是压暗蒙版。
只靠压暗会把照片压成灰块，反而廉价。

## 六、需要避开的东西（语料自己的毛病，已做成 G19 逐页拦）

`grade_exemplars.py` 把 2224 页逐页判过：**好示范 835 页（37.5%），坏示范 1389 页（62.5%），
171 册里有 117 册过半是坏页**。所以下面这些"语料里很常见"的做法一律不学，
且成品逐页命中就被 G19 拦（判据与分层同源：`corpus_tables.BAD_RULES`）：

- **推广页污染（504 页）**：猫仔吉祥物"视频教程/相关推荐/免费模版"、网盘链接+提取码、公众号二维码。
  一个 17 页的 deck 真设计内容可能只有 2–3 页。引用"每页字数中位 23.5、33.5% 页几乎无字"这类数时
  必须说明口径——**好示范子集里满幅压字占 58.3%，不是原始的 27.3%**。
- **无字无信息空页（560 页）**：好示范里剩下的无字页都带媒体或动效，纯装饰页不算。
- **字压亮底（346 页）**：文字区背景亮度中位 >0.55，字糊在亮照片/白柜上。这是缺陷不是手法；
  解法顺序见第五节（低噪声区 → 半透明卡片 → 描边/外发光 → 压暗蒙版），分栏原型直接不压图。
- **文字墙（70 页）**：单页 300 字以上，与"一页一意"相反。
- **没有视觉层级（20 页）**：整页最大字号 <14pt。好示范页的字号中位是 66pt。
- **模板编号当主视觉（16 页）**：把 NO.xxx 印在封面上，那是商品图不是汇报图。
- 模板自带的"下载链接+提取码"页要整页删掉，别当内容页复用。
