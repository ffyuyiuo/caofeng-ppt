## 2. 图片提示词 = 带标签九段式

语料里 NO.165 / NO.172 / NO.173 / NO.174 直接用小标题写出来，顺序固定：

```
生成一张 16:9 横版 <主题> PPT 背景图，整体采用<风格>，画面严格左右对称，正面平视视角，轻微广角透视。

主体特征：…
构图方式：…（含留白区与容器位置、占比）
镜头角度：…（等效焦距、机位、透视）
光线方向：…（主光 + 轮廓光 + 反射光 + 体积光）
色彩搭配：…（主色 + 辅色 + "避免其他颜色"）
材质细节：…
背景元素：…
画面风格：…（锚点：展厅/控制中心/宣传片 + 8K/HDR/电影级渲染）
画面参数：16:9，短边不低于 2160，无文字，无 Logo，无水印
```

### 位置量化是本技能强制项

语料里最高级的几条把版面**当工程图写**（NO.145 图片提示词）：

> 每个卡片约占画面宽度 30%、高度 14%……左上卡片位于画面左侧约 5%～35% 区域，右上卡片位于 64%～94% 区域；
> 左下卡片位于 5%～35% 区域，右下卡片位于 64%～94% 区域。四个卡片之间保持高度对称和统一间距。

为什么必须这样写：这样生成的图**天生就是可编辑 PPT 的容器**，文字层直接落进空框，不用二次修图。

## 3. 视频提示词 = 六段式

```
以<附件N>作为首帧，画面唯一的构图、透视、配色依据就是它。生成一段约 8 秒、16:9 横版、超高清的<主题> PPT 动态背景视频。
整体延续首帧的<风格>，严格保持首帧画面的构图、主体位置与色彩不变，只允许下列指定元素运动。

【0—2 秒：起势】…
【2—4 秒：展开】…（此处必须写"容器内部保持完全空白，不生成任何文字、数字、字母、图标、数据或图表"）
【4—6 秒：成形】…
【6—8 秒：定格收束】…最后约 0.5 秒画面稳定停留，最终画面必须与首帧参考图的构图和元素位置精准匹配。

【动作与顺序的硬性要求】前一阶段完成后才能进入下一阶段，不得同时、不得跳过、不得提前点亮。
【镜头与运动约束】镜头全程保持稳定平滑，只做极缓慢推进（幅度不超过画面 5%），不推拉突变、不旋转、不变焦、不穿模。
【严格限制】全片禁止出现任何文字、数字、字母、Logo、水印、字幕；不要新增首帧中不存在的物体。
【负面提示词】…
画面比例：16:9；视频时长：8 秒；画质：4K 超清，电影级渲染。
```

## 3b. 动图（GIF）提示词 = 六段式

**来源交底**：52 个真实提示词块里没有独立的动图块（那些是文生图与图生视频）。这一套是从
**161 个 GIF 的物理特征反推**的写法（帧数最少 24、中位 51；常见 426x240 / 1138x640 / 800x800；
用法是开场或元素级动效），六段与视频语法同源：

| 段 | 写什么 | 为什么要写 |
|---|---|---|
| 参考图声明 | 「附件1 只作构图与色域依据，不要求像素级复刻」 | 动图要重画一遍，照抄参考图会糊 |
| 全局参数 | 尺寸、时长 3–6 秒、帧率、风格基调 | 决定文件体积与循环顺滑度 |
| **循环声明** | 「首尾画面完全一致，无缝循环，不播一次就停」 | 不写就得到一段"放完不动"的伪动图 |
| 秒级分镜 | 一个元素一条运动线（水墨晕开 / 扇子旋转 / 光带划过） | 多元素同时动 = 闪烁噪点 |
| 运动约束 | 「除该元素外画面其余部分完全静止，不推拉不旋转」 | 动图当背景用时会抢文字 |
| **背景与叠加** | 「透明底或纯黑底，不得自带文字、边框、水印」 | 装配时叠在蒙版之上，带底色会露出一块方框 |

`pack`/`check` 的 G2 按 **6/6 段且 ≥300 字**核，并要求出现"循环"与"底色"两类声明；
G11 数的是文件**真实帧数**（<10 帧直接不合格），因为单帧 GIF 在 PowerPoint 里看着完全正常。

## 4. 负面提示词 = 三类名词清单


8 段负面全部落这三类，用顿号连接，**不写动词句**：

1. 技术缺陷：低清晰度，模糊，噪点，过度曝光，色彩溢出，塑料质感，锯齿，粗糙边缘
2. 内容禁区：文字，数字，字母，Logo，水印，字幕，人物，边框
3. 结构一致性：主体变形，结构断裂，透视错误，元素重复，相互穿插，车辆悬浮，车轮畸形，
   画面闪烁，镜头剧烈抖动，跳切，多余物体

真实样本（NO.173 智能仓储）：

> 低清晰度，模糊，噪点，过度曝光，色彩脏乱，暗黑工业风，老旧仓库，杂乱货物，破损设备，弯曲变形的货架，
> 错误的透视关系，输送带断裂，货物悬空，卡车结构错误，重复车辆，畸形车轮，机器人结构异常，设备相互穿插，
> 过多人物，拥挤场景，卡通风格，手绘风格，扁平插画，过度赛博朋克，夸张霓虹灯，文字乱码，水印，Logo，边框。

第 3 类是这套语料区别于普通提示词的地方：**它把"模型容易画错的具体结构"逐个点名**，
而不是笼统写"低质量"。写负面时必须先想"这个场景模型会画坏在哪"，再逐条列。

## 5. 图生视频（有爬到的素材时，优先走这条）

```
以当前上传的<素材描述>图片作为首帧，以指定的<目标描述>图片作为最终结尾帧，
生成一段约 6 秒、16:9 横版、连续自然的<风格>动态视频。
首帧状态：视频开始时严格保持首帧画面的视觉风格……
0-1 秒｜…  1-2 秒｜…  2-3 秒｜…  5-8 秒｜…
最后 0.5 秒画面逐渐稳定，最终精准匹配结尾参考图片的构图和元素位置。
```

四条铁律（语料原文）：

- **"两张参考图是同一场景的不同拍摄机位，不是两个需要直接拼接的独立场景"**——不写这句，模型会交叉溶解或硬切。
- **"主体大小与位置保持不变，只让背景随运动变化"**——语料根目录那条独立教程（逐字稿 `2088903e…txt`，78.5 秒）
  的原话是"船的大小和位置保持不变，风景随航行变化"。这是**一张静帧做成整页动态背景**最省事的写法：
  不写这句，模型会推着整幅画面一起动，前景主体变形、文字区跟着漂；写了这句，主体钉住，
  只有环境在变，铺满整页后仍能压住文字。同一条教程还确认了装配顺序：图生视频 → 导入 PPT 铺满整页 →
  设为放映时自动循环播放 → 最后才加标题与内容并给淡入。

- **"通过连续、平滑、符合真实摄影机运动规律的镜头移动，完成从高空远景到低空近景的视觉过渡"**。
- **"手指点击不是装饰，而是整个城市生长动画的触发动作。点击之前不能生长，必须点击之后才开始生长"**——
  任何"因果"动作都要这样显式写死。

## 6. 循环背景（适合 PPT 长时间停留）

语料里 NO.173 仓储、NO.157 风车、NO.138 旋转风车都用循环写法：

> 升降机从当前位置缓慢上升，到达较高位置后短暂停留，再平稳下降回原位置，随后不断重复上下循环。
> 每当一辆货车离开后，一辆外观相同的蓝色厢式货车从对应装卸门后方的通道驶入空出的车位……三辆车持续按照相同顺序循环发车和补位。

要点：**每个运动体都要写"回到初始位置/循环补位"**，并要求"摄像机完全静止，不推拉、不旋转、不变焦"，
这样首尾一致，PPT 里循环播放不跳帧。

## 7. 交付前自检（`pack` 会拦这些，`check` 用同一套判定重跑一遍）

- 图片提示词 ≥7/9 段且 ≥350 字；视频 **6/6** 段且 ≥400 字；动图 **6/6** 段且 ≥300 字。
  （数字的唯一来源是 `caofeng.py` 的 `TH` 表，SPEC §7.1 逐键对账。）
- 必含"留白/空白/不放任何文字"声明。
- 必含"无文字/无 Logo/无水印"禁令。
- 视频必含"附件/首帧/尾帧"点名；动图必含"无缝循环"与"透明/纯黑底"。
- 负面单独成段。
